# Deliberately small. Everything heavy that could be a subprocess is one:
# ffmpeg and ffprobe are invoked, not wrapped.
#
# **Minimums, not pins.** The first version of this file pinned exact releases
# and the install failed on the actual machine: it runs Python 3.14 with
# ffmpeg 8, and the pinned PyAV and Pillow had no wheels for either, so pip
# tried to COMPILE them and died against an ffmpeg API three major versions
# newer than those releases knew about. Pinning is the right instinct for a
# product's own dependencies; here it pinned this worker to a machine that
# does not exist. Floors let pip pick the wheel that matches the interpreter
# it finds, and every one of these is a well-behaved library rather than
# something whose minor releases move under us.
httpx>=0.27
# Transcription. `small.en` on CPU with int8 — the GPU on the render machine is
# shared with another project. Pulls ctranslate2, onnxruntime and PyAV.
faster-whisper>=1.0
# Spelling numbers out for the narrator. Without it "$450,000" is read as
# digits, which is exactly how a published short ended up saying "one zero
# three four zero".
num2words>=0.5
# Kling signs its requests with a short-lived JWT from an access/secret pair.
PyJWT>=2.8
# The watermark check renders a frame and compares it against the mark. Without
# Pillow that check REFUSES rather than passing quietly — a verification that
# silently returns "fine" when it could not run is worse than none.
Pillow>=10.4
